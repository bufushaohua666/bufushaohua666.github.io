# 168TI · 高中人格诊断


## 简介

一份专属于 **合肥168中学** 校友的人格诊断测试。  
题目设置一共有 9 道必答题 + 1 道彩蛋题。

---

## 玩法

1. 点击「开始诊断」
2. 按真实感觉选出 9 道题的答案（单选）
3. 最后选出你最怀念的 168 瞬间（可以多选）
4. 查看你的 **168TI 人格类型** + 匹配度排名

## 彩蛋题

最后一道彩蛋题，部分人格需要满足特定彩蛋条件才能解锁。  
试试看你能不能触发隐藏路径。😼

---

## 技术实现

- 纯前端静态页面（HTML + CSS + JavaScript）
- 采用 **加权曼哈顿距离** 算法计算匹配度
- 支持 **选项池匹配**（例如某一题选A/B都符合某一个人格设定）
- 支持 **彩蛋解锁条件**（部分人格需满足彩蛋条件）
- 部署于 GitHub Pages
